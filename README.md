# VB compatible docfx2
A modified version of [docfx2](https://github.com/dotnet/docfx) that generates Visual Basic member declarations.

## Usage differences
- Command `docfx` -> `docfx2vb`
- Replaced built-in templates:
    - [default-vb-declaration](https://github.com/Nukepayload2/docfx-v2-vb-templates/tree/main/default-vb-declaration)
    - [modern-vb-declaration](https://github.com/Nukepayload2/docfx-v2-vb-templates/tree/main/modern-vb-declaration)
